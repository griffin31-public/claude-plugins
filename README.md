# Griffin31 plugins for Claude

Claude Code plugins from [Griffin31](https://www.griffin31.com), Microsoft 365 security posture management.

| Plugin | What it does |
|---|---|
| [griffin31](plugins/griffin31) | Get started on a Griffin31 account, triage open recommendations and remediate them in the Microsoft portals with evidence. |

## Install

```bash
claude plugin marketplace add griffin31-public/claude-plugins
```

```bash
claude plugin install griffin31@griffin31-plugins
```

See the [plugin's README](plugins/griffin31) for setup.
